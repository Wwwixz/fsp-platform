# ФСП — платформа спортивного программирования (фронтенд)

React 19 + TypeScript + Vite + Tailwind CSS. Реализованы: **лендинг**,
**вход/регистрация**, **соревнования** (список + детали), **команды**,
**личный кабинет спортсмена**, **результаты**, **аналитика организатора**,
**заявки на участие**.

Данные моковые, аутентификация демонстрационная (localStorage).
При регистрации можно выбрать роль: **спортсмен** или **региональный представитель**
(организатор).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (если 502 — используйте --host и сетевой адрес)
```

## Сборка

```bash
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

## Структура

```
src/
  auth/          AuthContext — мок-авторизация (localStorage, роли)
  components/    PublicHeader, Header, AppShell, BarChart, Avatar,
                 StatusBadge, Logo, AuthLayout, иконки
  data/          mock.ts (данные), navigation.ts (пункты меню по ролям)
  pages/         Landing, Competitions, CompetitionDetails, Teams, Cabinet,
                 LoginPage, RegisterPage, AnalyticsPage, ResultsPage,
                 ApplicationsPage
  styles/        global.css — дизайн-токены (страницы авторов/организатора)
```

Две дизайн-системы сосуществуют: страницы лендинга/кабинета/соревнований —
на Tailwind (спека из HTML-макета), страницы авторизации/результатов/аналитики —
на `global.css` (код второго фронтендера). Tailwind подключается первым
(`App.css` → `styles/global.css`), чтобы element-правила global.css имели приоритет.

## Маршруты

| Путь                | Страница                          | Доступ                      |
| ------------------- | --------------------------------- | --------------------------- |
| `/`                 | Лендинг                           | —                           |
| `/competitions`     | Список соревнований               | —                           |
| `/competition/:id`  | Детали соревнования               | —                           |
| `/teams`            | Рейтинг команд                    | —                           |
| `/login`            | Вход                              | —                           |
| `/register`         | Регистрация (спортсмен/организатор)| —                          |
| `/cabinet`          | Личный кабинет спортсмена         | Вход                         |
| `/results`          | Результаты (фильтры)              | Вход                         |
| `/analytics`        | Панель организатора               | Только региональный представитель |
| `/applications`     | Заявки на участие                 | Только региональный представитель |
