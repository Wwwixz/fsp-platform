# ФСП — платформа спортивного программирования (фронтенд)

React + TypeScript (Vite). Реализованы страницы: **вход**, **регистрация**,
**аналитика**, **результаты**, **заявки на участие**.
При регистрации можно выбрать только одну из двух ролей: **спортсмен** или
**региональный представитель** (организатор). Данные моковые, аутентификация
демонстрационная (localStorage).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Сборка

```bash
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

## Структура

```
src/
  auth/          AuthContext — мок-авторизация (localStorage)
  components/    Header, AppShell, BarChart, Avatar, StatusBadge, иконки
  data/          mock.ts (данные), navigation.ts (пункты меню)
  pages/         LoginPage, RegisterPage, AnalyticsPage, ResultsPage, ApplicationsPage
  styles/        global.css — дизайн-токены и стили
```

## Маршруты

| Путь            | Страница                                     | Доступ                 |
| --------------- | -------------------------------------------- | ---------------------- |
| `/login`        | Вход                                         | —                      |
| `/register`     | Регистрация (спортсмен / региональный представитель) | —             |
| `/analytics`    | Панель организатора (аналитика)              | Региональный представитель |
| `/results`      | Результаты (с фильтрами)                     | Все после входа        |
| `/applications` | Заявки на участие (статусы, поиск, пагинация)| Региональный представитель |

«Аналитика» и «Заявки» — разделы регионального представителя: их видит только
он, спортсмена при прямом заходе перекидывает на «Результаты». После входа
представитель попадает на аналитику, спортсмен — на результаты.
Без входа все внутренние страницы редиректят на `/login`. В меню ссылки
на ещё не реализованные разделы (Соревнования, Команды и т.д.) пока не активны.
