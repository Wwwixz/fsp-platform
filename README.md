# ФСП - Всероссийская Федерация спортивного программирования

Лендинг-страница официального сайта Всероссийской Федерации спортивного программирования.

## Особенности

- Современный и адаптивный дизайн
- Водяной градиент и прозрачные элементы
- Анимированные переходы и hover-эффекты
- Поддержка мобильных устройств и планшетов
- Статистика ближайших соревнований
- Детали об each дисциплине
- CTA-блок для быстрой регистрации

## Стэк технологий

- React с TypeScript
- Tailwind CSS для стилизации
- Vite для быстрой разработки
- Современные CSS-свойства (CSS Grid, Flexbox, backdrop-blur)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Демо


## Настройки адаптивности

- Мобильные устройства (до 768px): 1 колонка
- Планшеты (от 768px): 2 колонки
- Десктоп (от 1200px): 4 колонки
