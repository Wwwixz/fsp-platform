# Гео-Динозавр 🦖🌐

Раннер-викторина в стиле «динозаврика Chrome»: динозавр бежит, перед каждым
кактусом игра задаёт вопрос по географии. Правильный ответ разрешает прыжок,
неправильный завершает попытку. После забега — экран результатов с мемом,
статистикой и прогресс-баром. Кнопка «Дальше» запускает видео, после которого
автоматически начинается новая игра.

## Запуск

Открой игру через локальный сервер, чтобы браузер корректно загружал и
проигрывал видео (зависимости для сервера не нужны):

```bash
cd geo-dino
node serve.cjs 8099
# http://localhost:8099
```

Игру также можно открыть напрямую как `index.html`, но браузер может
заблокировать локальное видео. В таком случае открой игру через указанный сервер.

После успешного запуска workflow GitHub Pages игра будет доступна по адресу:
https://wwwixz.github.io/fsp-platform/

## Управление

| Действие                | Мышь / тач               | Клавиатура        |
| ----------------------- | ------------------------ | ----------------- |
| Начать игру             | кнопка «Играть»          | `Space` / `Enter` |
| Ответить на вопрос      | кнопка ответа            | `1`–`4`           |
| **Прыжок**              | тап/клик по игровому полю| `Space` / `↑` / `W` |
| Продолжить после результата | кнопка «Дальше»       | `Space` / `Enter` |
| Звук вкл/выкл           | кнопка 🔊 в HUD          | —                 |

Как это работает: перед каждым кактусом игра останавливается и задаёт вопрос.
Правильный ответ **открывает прыжок** — но прыгает сам игрок и сам выбирает момент
(нажми пробел или тапни по экрану). Прыгнул рано или поздно — врежешься.
Неправильный ответ завершает попытку. После столкновения сразу показывается
экран результата с процентом и рекордом. Пока препятствие не пройдено,
прыгать можно сколько нужно (после приземления), как только кактус позади —
прыжок закрывается до следующего верного ответа.

## Экран

Игра занимает всё окно браузера (высота `100dvh` — корректно с адресной
строкой мобильных браузеров), горизонтальная прокрутка исключена.
Итоговый экран с мемом отображается сразу после проигрыша поверх игрового
поля; на нём три колонки (результат + прогресс-бар, мем,
статистика), на планшете — две, на мобильном — одна вертикальная со
скроллом внутри оверлея.

## Правила подсчёта очков

- **Счёт** — количество пройденных препятствий: 1 препятствие = 1 очко
  (один вопрос + один прыжок). Скорость растёт с каждым очком.
- **Мемы по процентам:** `0–19%` использует `0-20.png`, далее PNG выбирается
  по имени диапазона (`20-30.png`, `30-40.png` и т. д.). В диапазонах без
  отдельного PNG показывается SVG-мем; результат выше 100% использует `90-100.png`.
- **Процент результата** показывается отдельно от мема всегда, в том числе
  при 0 очков («Твой результат — 0%»).
- **Рекорд** — лучший счёт, сохраняется в `localStorage` и переживает
  закрытие браузера.
- **Шкала итогового экрана** ограничена 100 очками: полоса заполняется как
  `min(счёт, 100)%`. Если счёт превысил 100, показывается фактическое число
  («выше шкалы 100»), полоса остаётся полностью заполненной — прогресс не
  обрезается и не отображается как «N/100» сверх шкалы.
- **Категории результата** (у каждой свой мем, описание и акцентный цвет):
  0–9 «Новичок-путешественник», 10–24 «Юный турист», 25–49 «Путешественник»,
  50–74 «Исследователь», 75–99 «Географ», 100+ «Магистр географии».

## Структура проекта

```
geo-dino/
  index.html          разметка всех экранов
  css/style.css       стили, палитра референса, адаптив и анимации
  js/config.js        настройки и константы (скорости, физика прыжка, шкала)
  js/storage.js       рекорд и настройка звука (localStorage, безопасно)
  js/sprites.js       пиксель-арт спрайты (динозавр, кактусы, облако)
  js/questions.js     72 вопроса, включая блок об Африке, и банк с перемешиванием
  js/memes.js         категории результатов, SVG-мемы и выбор PNG по диапазону
  js/audio.js         звуковые эффекты на Web Audio (синтез, без файлов)
  js/world.js         canvas-мир: земля, горы, облака, кактусы, динозавр, пыль
  js/game.js          конечный автомат состояний и игровой цикл (rAF, dt)
  js/ui.js            DOM-интерфейс: HUD, карточки, тосты, экраны
  js/main.js          сборка и обработка событий
  png/                мемы по процентным диапазонам и видео после результата
```

Модули общаются через единый неймспейс `window.GeoDino`; сборщик и внешние
зависимости для запуска не нужны. Для воспроизведения видео используй локальный сервер.

## Технические заметки

- Игровой цикл один на всё приложение (`requestAnimationFrame`), движение
  рассчитывается по времени кадра (`dt`), после сворачивания вкладки `dt`
  ограничивается 50 мс.
- Состояния: меню → бег → вопрос → прыжок → столкновение → результат → видео
  → новая игра. После проигрыша процент и рекорд показываются сразу. При
  перезапуске очищаются все таймеры и препятствия,
  второй игровой цикл не создаётся.
- Широкие кактусы появляются только на высокой скорости — траектория прыжка
  (высота ≈ 160 px, время в воздухе ≈ 0.65 c) рассчитана так, чтобы прыжок
  всегда успевал их перелететь.
- Canvas рисуется с учётом `devicePixelRatio` (до 3×), спрайты — целыми
  пикселями без сглаживания.
- Звук включается только после первого действия пользователя; все эффекты
  синтезируются осцилляторами Web Audio, внешние файлы не нужны.
- Рендер и логика разделены: `world.js` только рисует и двигает, правила —
  в `game.js`, DOM — в `ui.js`.
